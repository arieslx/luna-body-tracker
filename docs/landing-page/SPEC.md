# Luna body tracker — Landing Page SPEC

> 静态宣传页面 · 中英双语 · BENTO 数字日记调性
> Version 0.1 · 2026-07-24

---

## 1. 目标与定位

### 1.1 这是什么

Luna body tracker 的**官方介绍页面**。多端轻记录"数字身体手帐"。

### 1.2 Landing Page 的目的

让一个**从未听过 Luna 的人**，在 30 秒内感受到：

> "分一点注意力给自己的身体，轻记录，迈向长期主义。"

副标题：轻触记录，慢慢相伴。

## 零负担落笔（Light Entry）

没有繁琐的必填项，没有复杂的数字计算。想记心情点一下，想写食物涂一笔。

## 无压力留痕（Stress-Free Journey）

没有“断更”警告，没有红色的未完成提示。哪天忘记了也没关系，每一页都是独立的温柔留白。

## 时间带来的复利（Long-Term Companionship）

当你把时间拉长，月相的更迭、睡眠的起伏、散步的轨迹……这些轻盈的点滴，最终会拼贴出你最真实、最温热的身体地图。

### 1.3 用户画像

画像一：压力型饮食观察者（应对情绪性进食）
特征：常因生活压力而出现间歇性暴食或饮食波动。对传统 App 严厉的“卡路里超标”警告极度敏感，容易产生负罪感和放弃心理。

Luna 的解法：“今日食物池”采用不打标签、不设红线的轻记录模式。它不是审判台，而是一面温和的镜子，帮用户在毫无压力的情况下感知饮食与情绪的联动。

画像二：极简营养践行者（“拳头饮食法”爱好者）
特征：知道基础的健康饮食结构（如“一拳主食、两拳菜、一到两拳肉”），但讨厌把每克食物放到秤上精算的压迫感，常常因为算卡路里太繁琐而导致营养摄入不均衡。

Luna 的解法：基于“拳头法则”设计可视化分类，放弃克重与能量计算。像在手帐上落小贴纸一样轻松点选，让用户用最轻盈的姿态感知今日营养是否凑齐。

画像三：身体周期联动感知者（经期与状态流）
特征：身体状态（如运动表现、精力、体重波动）受生理周期影响显著，迫切需要将经期、运动、睡眠放在同一个生活流中进行整体观察，而不是割裂在几个不同的专业工具里。

Luna 的解法：通过 Bento 模块化与月相、日期印章的结合，将经期、运动与日常留痕有机串联，直观且温柔地呈现身体在不同阶段的自然起伏。

画像四：情绪性延迟睡眠者（应对间歇性熬夜）
特征：白天工作消耗过大，夜晚感到“属于自己的时间被剥夺”，因而出现补偿性延迟入睡。传统睡眠软件的“时长不达标警告”或“打分”只会增加他们的负罪感。

Luna 的解法：睡眠卡片不打分、不出警示红字，只做事实型的温柔留痕。将睡眠与心情、运动等卡片放在同一个 Bento 页面中，不指责、只理解，让入睡不再带有心理负担。

### 1.4 关键决策

| 决策项 | 结论 |
| --- | --- |
| 产品名 | **Luna body tracker**（全名） |
| 平台定位 | Chrome 扩展，web页面，移动端响应式展示 |
| 文案语言 | 中英双语（中文主标 + 英文副标 / 装饰 scribble） |
| 中央图处理 | SVG 重画简化版（矢量清晰、可着色） |
| 身体周期模块 | 占位卡 + TBD 标签 |
| 交付方式 | 本地完成 → 一次性 `website_deploy` 上公网 |

## 2. 视觉规范

### 2.1 调性关键词

> **奶油白 · 低饱和 · 纸张感 · 手写排版 · 不规则但克制 · 温和不幼态**

### 2.2 色板（draft token，对照截图取色）

```
--color-cream:        #FAF6EF   /* 奶油白背景 */
--color-paper:        #F4ECE0   /* 略深纸张感，分区底色 */
--color-ink:          #3D3A36   /* 主文字，接近墨黑 */
--color-ink-soft:     #7A736C   /* 次级文字 */
--color-line:         #E5DDD0   /* 分割线、虚线 */
--color-pink:         #F2D7DC   /* 心情、情绪主色 */
--color-pink-deep:    #E8B6BE   /* 粉色强调 */
--color-sage:         #C8D8C4   /* 鼠尾草绿，食物/饮食 */
--color-sage-deep:    #9DB89A   /* 鼠尾草强调 */
--color-blue:         #CCD9E0   /* 雾蓝，水/睡眠 */
--color-blue-deep:    #9DB2BD   /* 雾蓝强调 */
--color-lavender:     #D9D2E4   /* 淡紫，备注/身体 */
--color-butter:       #F2E4B5   /* 淡黄，结果/高亮 */
--color-coral:        #E8A59A   /* 珊瑚，强调文字/按钮 */
```

色板取值原则：**全部 desaturate 到 30-50% 之间**，避开任何高饱和颜色。

### 2.3 字体

```
--font-zh:    "Noto Serif SC", "Source Han Serif", serif
              /* 中文用宋体，给"日记本"的纸质感 */
--font-en:    "Caveat", "Reenie Beanie", cursive
              /* 英文用手写体，做装饰和副标题 */
--font-ui:    "Inter", system-ui, -apple-system, sans-serif
              /* UI 数字、按钮用无衬线保持可读性 */
```

加载方式：Google Fonts 预连接（`rel="preconnect"`），不阻塞首屏。

### 2.4 排版尺度

```
--fs-display:  56px / 1.15  /* 首屏大标题 */
--fs-h1:       40px / 1.25
--fs-h2:       28px / 1.3
--fs-body:     16px / 1.7
--fs-small:    13px / 1.5
--fs-scribble: 18px          /* 英文手写副标 */
```

行高偏宽（1.7），呼应"日记不紧凑"的语感。

### 2.5 间距 / 圆角 / 阴影

```
--space-1: 4px
--space-2: 8px
--space-3: 16px
--space-4: 24px
--space-5: 40px
--space-6: 64px
--space-7: 96px        /* section 之间 */

--radius-sm: 6px
--radius-md: 12px
--radius-lg: 20px
--radius-card: 16px     /* 卡片标准圆角 */
--radius-blob: 24px     /* 漂浮卡片，用更大圆角增加柔和感 */

--shadow-paper: 0 1px 0 rgba(0,0,0,.04),
                0 8px 24px -8px rgba(60,55,50,.10)
                /* 模拟纸张悬浮，不重 */
--shadow-stamp: 0 2px 0 rgba(60,55,50,.08),
                0 4px 12px -4px rgba(60,55,50,.12)
```

### 2.6 纸张纹理

SVG noise 平铺背景，`opacity: 0.04`，不抢戏。

```css
background-image: url("data:image/svg+xml,...noise...");
background-size: 200px 200px;
```

### 2.7 不要出现的元素

- ❌ 渐变玻璃 / 毛玻璃
- ❌ 高饱和渐变色
- ❌ 卡通 emoji 大图（emoji 仅作为小尺寸标签）
- ❌ "立即下载"的大红按钮
- ❌ 传统 app store / google play 徽章墙
- ❌ 截图密集堆叠的"功能墙"
- ❌ 假皮革 / 假木纹 / 假胶带（**小刘明确反对 skeuomorphism**）

## 3. 信息架构（页面 6 段）

### Section 1 — 轻记录身体手帐

**目的**：30 秒传达"这是轻记录的身体手帐"。

**布局**：
- 顶部小标签：`Luna body tracker — A quiet place to notice your body`
- 主标题（中文宋体大字号）：`把身体当作一本，慢慢翻的手帐`
- 副标题（英文手写）：`a small ritual, not a streak`
- 中央：一台 SVG 重画的"手机浮窗"，承载完整 BENTO 界面
- 周围：4 张漂浮卡片（**身体周期 TBD 不出现在首屏，留到 Section 4 周回顾**）
  - 心情（粉色）："今天有点累 😅"
  - 喝水（雾蓝）：6/8 cups
  - 睡眠（淡紫）：23:00 - 7:30
  - 食物（鼠尾草绿）：一盘简笔画食物
- 装饰：日期贴纸 "July 24"、月相小图章、虚线分割、一条英文手写 scribble "tired today, but ok"
- 底部 CTA：浅色文字链接 `Install for Chrome →` github，私有化部署。

**关键参数**：
- 桌面：中央手机宽 320px，周围卡片 ± 1-3° 旋转，绝对定位重叠
- 移动端：单列堆叠，浮动卡片退化为静态小卡

### Section 2 — 留白与留痕：让身体回归日记的质感

**目的**：展示产品核心优势，传递“轻量、接纳、无压”的品牌态度。

**视觉布局**：两栏错位重叠的“小纸条”拼贴。

* **左上纸条（轻感知）**：鼠尾草绿/淡紫底色，呈现极简点选的轻盈感。
* **右下纸条（真接纳）**：奶油黄/暖白底色，呈现只有一个备注框的舒缓留白。

---

| 维度 | 极致的轻盈（Lightness） | 温柔的接纳（Acceptance） |
| --- | --- | --- |
| **视觉体验** | 奶油纸质与低饱和色彩，像翻开一本随手放在床头的身体手帐 |  |
| **交互体验** | **点一下即可留痕**：没有复杂的必填项，用最自然的方式随手记录 |  |
| **饮食感知** | 轻松点选拳头比例，用直观的结构看见今天凑齐的营养 |  |
| **睡眠记录** | 真实记录每一个早睡或晚睡的夜晚，不做判定，只做记录 |  |
| **文字表达** | **全页只有一个轻量备注框**：想写时落笔几字，不想写时优雅留白，三餐可以选择性记录 |  |

### Section 3 — 模块详解

**目的**：把现有 BENTO 5-6 个核心模块一一展示。

**布局**：纵向 4 段，每段"左文字 + 右模块卡"。

模块清单（按截图优先级）：

1. **心情**（粉色）— 选择表情
2. **水 / 睡眠**（雾蓝 + 淡紫）— 两个最简单的"身体节律"
3. **食物**（鼠尾草绿）— 不用算卡路里，只问"吃了什么"
4. **运动 / 结果 / 体重**（淡黄 + 珊瑚）— 数据属于你
5. **备注**（淡紫）— 自定义placeholder，补充今天。晨间日记/晚间日记/

每个模块：左侧标题 + 描述 + 一个英文 scribble，右侧 SVG 重画的迷你模块卡。

### Section 4 — 周回顾：把日子连成一条温热的河（Scrapbook 拼贴）

**目的**：用一整周的随手记录，传达"身体日记"和"打卡 App"最本质的区别——
不评判、不打断、不连续，只让"起伏"自然显现。

**视觉调性**：Scrapbook / 手账拼贴。**不画表格、不画图表**。
7 张小卡像被随手贴在桌面上，**有重叠、有旋转、有空白**。

#### 4.1 顶部装饰

- 左侧倾斜贴纸：日期区间 `Jun 22 — Jun 28`（鼠尾草绿）
- 右上英文 scribble：`Weekly Flow` 或 `a week, lightly held`
- 月相小图章（取这周内某一天的月相）
- 1-2 条手写英文批注：`sleep got better by Friday` `周一那条怒气没写完，没关系`

#### 4.2 7 天卡（核心）

| 周几 | 卡片色 | 重点指标（默认显示） | hover 展开（次要） | 备注 |
| --- | --- | --- | --- | --- |
| 周一 06/22 | 粉色 | 😤 愤怒 + "夜醒多次" | 运动：早操 / 喝水：1杯 | — |
| 周二 06/23 | 鼠尾草绿 | 😄 露齿笑 + "散步 30 min" | 睡眠数据 / 食物 | — |
| 周三 06/24 | 雾蓝 | 体重 72 KG + 游泳 | 心情 / 食物 | — |
| 周四 06/25 | 淡紫 | 😄 露齿笑 + "睡眠短" | 运动 / 体重 | — |
| 周五 06/26 | 淡黄 | 😄 露齿笑 + "游泳 + 增身" | 喝水 / 食物 | — |
| 周六 06/27 | 鼠尾草绿 | 😄 露齿笑 + "散步 + 早睡" | 食物 / 备注 | — |
| 周日 06/28 | **空白** | "今天不想写" + 虚线框 | — | **故意留空** |

**关键**：
- **周日是空白**——表达"不打卡也不焦虑"
- 卡片**大小不一**（160-220px 宽 × 140-180px 高）
- **错位旋转** ±2-4°，像被随手贴上
- **有重叠**：周二的右下角压在周三的左上角
- 不用 emoji 整张脸，只用**小圆脸 + 一个词**（避免幼态）

#### 4.3 身体周期 TBD 占位卡（放在 7 天卡之间）

- 一张**虚线边框**的卡，明显和实卡区分
- 中央手写体：`Cycle Tracking`
- 下方小字：`coming soon` + 月亮图标
- 颜色：纯虚线 + 淡紫文字
- 位置：放在周中某个位置（如周四和周五之间），暗示"未来会插在这里"

#### 4.4 底部金句

> **"把视角拉长一周，**
> **你会发现，所有的起伏都是身体最自然的呼吸。"**

#### 4.5 三个核心卖点（卡组下方，三栏小卡）

1. **看见节律** — 无需复杂图表，日子本身就是图谱
2. **多维联动** — 睡眠、心情、饮食、运动在周视图里自然相邻
3. **零断更焦虑** — 留白也是记录，没写的那天不会被打叉

## 5. 响应式

```
Desktop:  ≥ 1024px   完整 6 段
Tablet:   768-1023px  卡片堆叠为 2 列，时间线不变
Mobile:   < 768px     单列堆叠，hero 浮动卡变静态，时间线变短
```

移动端**不裁切内容**，只调整密度。

## 6. 可访问性

- 全部图片 `alt` 文案
- 颜色对比 ≥ 4.5:1（粉色文字需要加深）
- 装饰元素 `aria-hidden="true"`
- 滚动动效遵守 `prefers-reduced-motion`
